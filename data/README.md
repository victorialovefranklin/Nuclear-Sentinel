# Data inputs

Raw HAI/HAIEnd and SWaT datasets are intentionally **not redistributed in this public repository**.

## Experiment 1 — HAI/HAIEnd
The Experiment 1 script documents the expected HAI 23.05 and HAIEnd 23.05 train, test, label, and summary-label files.

## Experiments 2–3 — SWaT A1
Expected local inputs:
- `SWaT_Dataset_Normal_v1.csv` or `.xlsx`
- `SWaT_Dataset_Attack_v0.csv` or `.xlsx`
- `List_of_attacks_Final.csv` or `.xlsx` where required

Place authorized copies locally before running the scripts.

## Why raw data are excluded
The SWaT files used in the analysis are large (well above GitHub's normal per-file push limit for some files), and public redistribution should follow the original dataset provider's access/licensing terms. The repository therefore publishes code, derived result tables, figures, audit outputs, and input manifests rather than republishing the raw datasets.
